基于多智能体强化学习的城市交通信号协同控制方法研究

摘　要

随着城市化进程不断加快，机动车保有量持续攀升，城市道路交通拥堵问题日益严峻，传统的固定配时与自适应单点控制方法难以应对大规模路网中交通流的动态性与随机性。针对这一问题，本文提出一种基于多智能体强化学习（Multi-Agent Reinforcement Learning, MARL）的区域交通信号协同控制方法。首先，将路网中每个交叉口的信号机建模为一个智能体，设计了融合排队长度、相位饱和度与路网拓扑结构的复合状态空间，并构建了以平均车辆延误、停车次数与排队长度加权的多目标奖励函数；其次，引入图注意力网络（Graph Attention Network, GAT）对路网拓扑关系进行编码，使各智能体能够在集中式训练分布式执行（CTDE）框架下实现邻居信息共享与策略协同；最后，基于 SUMO 微观交通仿真平台构建了包含 12 个交叉口的城市区域路网实验场景，与固定配时、Webster 配时及独立 DQN 三种基线方法进行了对比实验。实验结果表明，本文方法在高峰时段将路网平均车辆延误降低了 18.6%，平均排队长度降低了 22.3%，路口总通行量提升了 9.4%，验证了多智能体协同控制在区域信号配时优化中的有效性。

关键词：多智能体强化学习；交通信号控制；图注意力网络；智能交通系统；SUMO 仿真

Abstract

With the acceleration of urbanization, traffic congestion has become a severe problem in modern cities. Traditional fixed-time and adaptive single-point control methods can hardly handle the dynamics and stochasticity of traffic flow in large-scale road networks. This thesis proposes a regional traffic signal coordination method based on Multi-Agent Reinforcement Learning (MARL). Each intersection signal controller is modeled as an agent with a composite state space integrating queue length, phase saturation and network topology, and a multi-objective reward function weighted by average vehicle delay, number of stops and queue length. A Graph Attention Network (GAT) is introduced to encode the road network topology, enabling neighbor information sharing under the Centralized Training with Decentralized Execution (CTDE) framework. Experiments on a SUMO-based simulation network with 12 intersections show that the proposed method reduces average vehicle delay by 18.6% and average queue length by 22.3% during peak hours, while improving total throughput by 9.4%.

Key words: Multi-Agent Reinforcement Learning; Traffic Signal Control; Graph Attention Network; Intelligent Transportation System; SUMO Simulation

第1章　绪论

1.1　研究背景与意义

城市交通是城市经济运行的大动脉。近年来我国机动车保有量已突破 4 亿辆，北上广深等特大城市高峰时段主干道平均车速不足 20 km/h，交通拥堵不仅造成巨额经济损失，也加剧了能源消耗与尾气排放。信号交叉口是城市路网的咽喉，其配时方案的优劣直接影响路网的整体运行效率。因此，如何对区域范围内多个交叉口的信号进行协同优化，是智能交通系统（Intelligent Transportation System, ITS）领域长期以来的核心研究问题之一。

1.2　国内外研究现状

早期的交通信号控制以 Webstar（Webster）延误公式为基础的经典配时方法和 SCATS、SCOOT 等传统自适应系统为代表，其依赖人工标定的数学模型，难以适应交通流的强非线性和突变场景。近年来，随着深度强化学习的发展，DQN、DDPG、PPO 等算法被相继应用于单交叉口信号控制，并取得了优于固定配时的效果。然而，单点最优并不等于全局最优：各交叉口独立决策容易引发"绿波带断裂""排队溢出"等协调失效问题。多智能体强化学习通过联合策略学习与通信机制实现 agent 间的显式协同，为区域信号协同控制提供了新途径，但现有方法普遍面临部分可观测、信用分配困难与训练不稳定等挑战。

1.3　主要研究内容与组织结构

本文的研究内容围绕"建模—协同—验证"三个层面展开：其一，建立面向区域路网的交通信号马尔可夫决策过程（MDP）模型；其二，设计基于图注意力网络的智能体间通信与协同训练机制；其三，搭建 SUMO 仿真实验平台开展多场景对比验证。全文共分五章：第1章绪论；第2章相关理论基础；第3章基于图注意力的多智能体协同控制方法设计；第4章实验与结果分析；第5章总结与展望。

第2章　相关理论基础

2.1　马尔可夫决策过程与强化学习

强化学习（Reinforcement Learning, RL）研究智能体如何在与环境的交互中通过试错学习最优策略。其数学基础是马尔可夫决策过程，由五元组 (S, A, P, R, γ) 描述，其中 S 为状态空间，A 为动作空间，P 为状态转移概率，R 为奖励函数，γ 为折扣因子。Q-learning 通过迭代更新动作价值函数 Q(s,a) 逼近最优策略；深度 Q 网络（DQN）则用神经网络逼近 Q 函数，并引入经验回放与目标网络稳定训练过程。

2.2　图注意力网络

图神经网络（GNN）擅长处理非欧几里得结构数据。图注意力网络（GAT）在聚合邻居信息时引入注意力机制，对不同邻居节点分配不同权重 α，可有效刻画交叉口之间影响强度的差异，适合建模城市路网的拓扑结构。

2.3　多智能体强化学习与 CTDE 框架

多智能体强化学习（MARL）面临环境非平稳问题：某一智能体策略更新会使其他智能体所处的环境发生改变。集中式训练分布式执行（CTDE）框架在训练阶段允许利用全局信息（全局状态、联合观测）进行中心化价值评估，而在执行阶段每个智能体仅依据本地观测选择动作，兼顾了训练稳定性与部署可行性。QMIX、MADDPG 均是 CTDE 框架下的代表性算法。

第3章　基于图注意力的多智能体协同控制方法设计

3.1　问题建模

将研究区域内的 N 个信号交叉口建模为 N 个智能体。状态空间 s_i 包含：交叉口各进口道排队长度、当前相位剩余时间、相邻交叉口的排队状态摘要以及路网邻接特征。动作空间采用相位切换决策：保持当前相位或切换至下一个候选相位（绿灯最短时长约束下）。奖励函数设计为 r = -w1·D - w2·Q - w3·S，其中 D 为平均车辆延误，Q 为平均排队长度，S 为停车次数，w1、w2、w3 为可调权重，取值 0.5、0.3、0.2。

3.2　网络结构设计

每个智能体的 Q 网络由三部分组成：（1）本地特征编码器，采用三层全连接网络编码本地观测；（2）图注意力通信层，以交叉口为节点、连接路段为边构建路网图，经过两层 GAT 聚合邻居嵌入；（3）决策输出头，输出各候选动作的 Q 值。训练采用 QMIX 式的混合网络对联合价值函数进行单调性约束，保证分布式策略与中心化评估的一致性。

3.3　训练流程

训练阶段采用集中式 Critic 利用全局状态评估 TD 误差，经验回放池容量设置为 100000，批大小 256，学习率 5e-4，折扣因子 γ=0.95，探索采用 ε-greedy 策略且 ε 从 1.0 线性衰减至 0.05。整个训练过程在 SUMO 与 Python 联合仿真环境中进行，单轮训练采集一个完整高峰场景（3600 仿真秒）的交互数据。

第4章　实验与结果分析

4.1　实验环境

仿真平台采用 SUMO 1.19 搭配 TraCI 接口，路网为 3×4 网格布局共 12 个信号交叉口，主干道双向六车道，次干道双向四车道。交通需求设置早高峰（07:00-09:00）与晚高峰（17:00-19:00）两个场景，需求矩阵基于某市卡口检测数据缩放生成。对比基线包括：固定配时（FT，周期 120s）、Webster 最佳配时（Webster）、独立 DQN（I-DQN，无通信）。

4.2　评价指标

采用平均车辆延误（Average Delay, s/veh）、平均排队长度（Queue Length, veh/lane）、路网总通行量（Throughput, veh）与停车率（Stop Rate, %）四项指标，每个方法独立运行 10 次取均值与标准差。

4.3　结果与分析

实验结果显示：在早高峰场景下，本文方法平均延误为 27.4 s/veh，较固定配时（33.7）、Webster（32.1）与独立 DQN（30.5）分别降低 18.7%、14.6% 与 10.2%；平均排队长度降低 22.3%；总通行量提升 9.4%。消融实验进一步表明：移除图注意力通信层后性能下降 6.8 个百分点，验证了邻居协同信息的重要性；将奖励函数简化为单一延误目标会导致停车率上升 11.3%，说明多目标奖励设计的必要性。此外，在突发事故场景（主干道单车道封闭 20 分钟）中，本文方法的自适应恢复时间较基线缩短约 35%。

4.4　训练收敛性分析

训练曲线表明算法在约 1800 个训练回合后趋于收敛，混合网络损失平稳下降，未出现明显的策略震荡，证明单调性约束对多智能体训练稳定性的贡献。

第5章　总结与展望

本文面向城市区域交通信号协同控制问题，提出了基于图注意力网络与 CTDE 框架的多智能体强化学习方法，并通过 SUMO 仿真实验验证了其相对传统配时与独立学习方法的有效性。研究成果对提升路网运行效率、缓解城市交通拥堵具有一定的理论意义与应用价值。未来工作将从三方面展开：（1）引入真实路网检测数据，研究仿真到现实（Sim2Real）的迁移方法；（2）考虑公交优先与行人过街等多模式交通需求；（3）探索基于大语言模型的交通管控知识注入，提升策略的可解释性。
