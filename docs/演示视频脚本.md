# 演示视频脚本（5–8 分钟 · MP4 1080p）

> 比赛硬性要求：视频必须包含 **≥2 分钟「AI 协同过程复现展示」**（第 5 节）。
> 录制工具建议：OBS Studio（免费）或 Win+G Xbox Game Bar。分辨率 1920×1080，麦克风收音清晰。

---

## 0. 开场（20 秒）

**画面**：应用首页全屏（已上传好论文的状态更佳）

**口播**：
> 每年百万毕业生答辩前，只能对着空气练习。我做了「赛博答辩厅」——把答辩委员会搬进浏览器，五位 AI 评委将对你的论文展开全真质询。这是一场由多智能体编排驱动的模拟答辩，全程 Vibe Coding 开发。

## 1. 备战向导（60 秒）

**操作**：拖入论文 PDF → 展示解析进度 → 指出统计信息

**口播**：
> 第一步上传论文。注意——PDF 解析完全在你的浏览器本地完成，论文不上传任何服务器。系统用 pdf.js 抽取全文、按语义分块 83 块、构建 BM25 索引，这个索引是后面评委提问的"事实锚"——每位评委的问题都必须建立在检索到的真实论文片段之上，从机制上杜绝 AI 幻觉。

**操作**：展示配置项，开启压力模式

> 答辩类型、学科领域、质询轮数都可以配置。打开压力模式，评委会更尖锐，末轮还有连环追问。API Key 填自己的 DeepSeek Key，只存在本地浏览器。

## 2. 多智能体答辩现场（2 分钟 · 核心演示）

**操作**：点击「开始答辩」，让画面自然播放；期间用鼠标拖动画布节点、指认消息流

**口播（配合画面节奏）**：
> 开始答辩。画布上，答辩人居中，四位评委环绕，主席居上。看边的流动——琥珀色的边是评委质询，青色回流是答辩作答，节点上的徽标实时显示"思考中/发言中"。
>
> 注意评委的问题：严博导直插方法论要害；温和教授的问题看似轻柔实则极深；行业专家追问落地价值；青年学者对标最新研究。**关键机制**：每位评委都能看到此前的问答记录——后面的评委会顺着前面暴露的疑点继续深挖，这就是多智能体的"联动"，而不是四个孤立的聊天机器人。
>
> 右侧消息流里，每个问题都标注了它引用的论文片段编号——这是 RAG 锚定的直观证据。

**操作**：中途点击「中止」→「直接评分」（或让它跑完）

## 3. 评分与终评报告（60 秒）

**操作**：展示雷达图逐项指点 → 滚动浏览终评报告 → 点击导出 .md

**口播**：
> 质询结束，四位评委独立提交五维评分：选题意义、创新性、方法严谨、表达答辩、工作量。雷达图上每个评委一条轨迹，中心渐变面积是委员会平均分。
>
> 最后，主席生成终评报告：总体评价、本场最尖锐的三个问题、薄弱环节诊断、按优先级排序的改进建议清单、答辩技巧提示——每一条都具体可执行，这就是结构化反馈的价值。一键导出 Markdown，练习成果可沉淀。

## 4. 架构速览（40 秒）

**画面**：切到 README 的架构图（或 IDE 目录树）

**口播**：
> 工程上：前端 React 19 + React Flow 画布 + zustand 状态机；检索层是手写的 BM25，中文 bigram 分词，零外部向量服务；编排引擎驱动"开场→质询→追问→评分→终评"全流程，网络错误自动重试、全程可中止；后端只有一个 150 行的 Express 流式代理，白名单透传、错误中文化。整个系统只有一个外部依赖——你自己的 DeepSeek Key。

## 5. AI 协同过程复现（≥2 分钟 · 硬性要求）

**画面**：分屏或切换展示——左侧 IDE（本项目 ZCode/Cursor 会话），右侧浏览器跑应用

**操作 A（Prompt 演进链）**：
> 开发过程我用 PROMPT_LOG 记录了完整的人机协作链。给大家看三个真实片段。
> 第一段：我提出"评委提问必须锚定论文真实内容、不许编造、不许重复提问"的意图约束，AI 生成了包含五条"提问纪律"的 System Prompt 模块；
> 第二段：开发中真实踩坑——pdfjs v6 移除了 `destroy` 方法导致编译失败，我把报错贴给 AI，它定位到 loadingTask 生命周期并修复；
> 第三段：评分 JSON 偶发解析失败，我描述"模型输出可能带 ```json 包裹"，AI 加了三重防御解析。

**操作 B（现场演示 AI 修改代码）**：
> 现场演示一次意图驱动迭代：我给 AI 输入需求（例如"在消息流卡片上加追问标记"），展示 AI 生成 diff → 保存 → 热更新后浏览器立即出现效果。
> （提前准备好这个改动，录屏时一气呵成）

**口播**：
> 我的角色不是写代码，而是定义问题、约束意图、验收引导——代码全部由 AI 生成。Git 历史按功能细粒度提交，每一次提交对应一次与 AI 的核心交互，整个项目的诞生过程完整可复现。

## 6. 收尾（20 秒）

**画面**：回到画布，答辩结束态 + 终评报告

**口播**：
> 赛博答辩厅，让每一次答辩练习都有真实对手和结构化反馈。答辩之前，先来一场赛博答辩。谢谢观看！
